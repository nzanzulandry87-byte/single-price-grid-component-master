## Overview

### The challenge

Build a responsive single price grid component that matches the provided design and works cleanly on mobile and desktop devices.

The main goals were:

- Create a layout that adapts to different screen sizes
- Display pricing and feature details with clear visual hierarchy
- Add a hover state for the Sign Up button on desktop
- Use semantic HTML and organized CSS

## My process

### Built with

- HTML5 semantic structure
- CSS3 styling
- Flexbox for the pricing layout
- Mobile-first approach
- Google Font: Karla

### What I learned

- How to structure content with semantic `<section>` elements.
- Why a global reset is useful for consistent spacing across browsers.
- How to use Flexbox for a two-column layout inside the pricing section.
- How to add a hover effect to a button using border and box-shadow styles.

### Continued development

For future improvements, I plan to:

- Add responsive media queries for smaller screens.
- Improve spacing and alignment for tablet and mobile views.
- Use CSS custom properties for colors and spacing.
- Add stronger keyboard focus styles for accessibility.
